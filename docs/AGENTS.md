# AGENTS.md

## Scope

- This file applies to `docs/`.

## What Lives Here

- Package-specific guides and developer workflow documentation for the Stark monorepo.
- The structure is organized primarily by package area such as `stark-build`, `stark-core`, `stark-rbac`, and `stark-ui`.

## Working Rules

- Keep docs aligned with the current package behavior and validation flow.
- Prefer package-specific guidance here. Keep migration review status in the root `IMPROVEMENT_PLAN.md` and downstream instructions in `MIGRATION_GUIDE_STARK_13.md` instead of duplicating either in package docs.
- When a source change affects user-facing usage or troubleshooting, update the closest matching doc page.
